🏷️ Murphy Tag Scanner

Enter any ORD — even a top-level path like station:|slot:/Drivers/NiagaraNetwork. The scanner recurses through all sub-folders until it finds folders tagged with MurphyTag:*, then reads each point's slot sheet for MurphyPoints:* to auto-assign Point IDs. Niagara ASCII encoding ($2d→-, $3a→:, $20→space, etc.) is decoded automatically.

ℹ️ MurphyTag:FTU on a device folder → shows the FTU Point ID dropdown for its points. The exported Type (sub-type like HEATE, COOL_HEAT, etc.) is still selected by you in the popup modals before export — exactly like the original script.
