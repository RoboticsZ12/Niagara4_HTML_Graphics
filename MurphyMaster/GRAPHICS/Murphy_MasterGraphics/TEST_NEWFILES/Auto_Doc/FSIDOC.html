Reference Sections

Reading What It Means Why It Matters
Rm TMP Actual air temperature in the room right now Compare to setpoint — shows if box is working
Temp Eff Spt The temperature the box is actively trying to maintain This is the real target — not just the base setpoint
User Spt Adjust Offset added by occupant or operator (+/– °F) Fine-tunes comfort without changing base setpoint
Airflow (cfm) Cubic feet per minute of air currently being delivered Higher = more cooling/ventilation; lower = less
Eff Flow Spt Target airflow the box is trying to hit right now Driven by box mode: Cool vs. Reheat
Damper Cmd (%) How open the damper is (0% = closed, 100% = fully open) Tracks airflow demand — should match Eff Flow Spt
Box Mode Current operating state: Cool or Reheat Tells you what the box is trying to do right now
Heat Stg 1 Whether the reheat coil is firing (Enabled / Disabled) Enabled = box is actively adding heat to supply air
DAT (°F) Discharge Air Temp — temperature of air leaving the box If reheating, this rises above RTU supply temperature
RTU Supply (°F) Temperature of cold air coming from the main air handler The raw cold air the VAV/FTU receives and modifies
Effective Setpoint Formula
Eff Spt = Base Spt + 2°F + User Adjust
When the room temperature climbs above the comfort deadband (Base + 2°F), the box enters Cool Mode. The effective setpoint shifts upward by 2°F, signaling the system to maximize cold airflow into the space.
  • 🔵
    Damper opens to deliver maximum cold supply air from RTU
  • 🔵
    Reheat coil remains OFF — no heating energy used
  • 🔵
    Airflow (cfm) should rise as damper opens further
  • 🔵
    DAT will be close to RTU supply temperature (no reheat)
Worked Example — VAV S110 Base Spt = 70.0°F  |  Mode = Cool  |  User Adjust = +0.5°F
Eff Spt = 70.0 + 2.0 + 0.5 = 72.5°F
Effective Setpoint Formula
Eff Spt = Base Spt – 2°F + User Adjust
When the room temperature drops below the comfort deadband (Base – 2°F), the box enters Reheat Mode. The effective setpoint shifts downward by 2°F. The reheat coil fires to warm the cold supply air before it enters the space.
  • 🟠
    Damper may reduce airflow to minimum position
  • 🟠
    Reheat coil turns ON — Heat Stg 1 = Enabled
  • 🟠
    DAT (discharge air temp) will rise above RTU supply temp
  • 🟠
    If DAT is NOT rising, suspect reheat coil issue
Worked Example — VAV S107E Base Spt = 70.0°F  |  Mode = Reheat  |  User Adjust = +1.2°F
Eff Spt = 70.0 – 2.0 + 1.2 = 69.2°F
Symptom Likely Cause What to Check
Room too warm,
box in Cool mode		 Damper not opening / low airflow from RTU Check Damper Cmd % vs. Airflow cfm. Verify RTU is running and supply temp is cold.
Room too cool,
box in Reheat mode		 Reheat coil not firing Check Heat Stg 1 — should be Enabled. Verify DAT is rising above RTU supply temp.
Effective Spt
seems wrong		 User Spt Adjust offsetting base Review User Spt Adjust. Recalculate: Eff Spt = Base ± 2°F + User Adjust.
Airflow doesn't
match Eff Flow Spt		 Damper stuck or calibration drift Compare Damper Cmd % to actual cfm. May need actuator inspection or recalibration.
